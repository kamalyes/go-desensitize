go-desensitize 解密调试台

把日志里的 enc:v1: 密文解回原文，或核对 ***xxxxxxxx 指纹对应哪个值

只从本地 file:// 打开，不要部署
带着密钥部署成网页，等于给所有能访问它的人开了一个解密预言机，比日志里直接存明文更糟 本页不引入任何外部资源、不发网络请求、不保存密钥，全部运算走浏览器自带的 WebCrypto

密钥 AES-128 / 192 / 256

与 SetDefaultCipher 用的同一把密钥，支持 base64 或 hex，自动识别

解密 enc:v1:

可以整段粘贴日志行，会自动找出其中所有密文逐个解开

指纹核对 ***xxxxxxxx

指纹不可逆，无法「解出」原值 但可以反向验证：给出候选原值，看它的指纹是否与日志里那串一致 不需要密钥

密文格式：enc:v1: + base64url(nonce[12] ‖ 密文 ‖ tag[16])，AES-GCM
指纹格式：*** + SHA-256(原值) 前 4 字节的十六进制
两者的生成端见仓库的 cipher.go 与 keyrules.go
